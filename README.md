# СОСТАВ.SCAN

Сканер состава продуктов — проверяет штрихкод или фото упаковки и подсвечивает вредные добавки и пальмовое масло. Сделан в первую очередь для пожилых людей: крупный текст, простой интерфейс, минимум лишних действий.

**Открыть приложение:** https://danya-bit0505.github.io/sostav-scan/

---

## Что умеет

- **Сканирование штрихкода** камерой или ручной ввод
- **Фото состава** — распознавание текста прямо на устройстве (без интернета для самого распознавания), если штрихкод не даёт результата
- Подсветка **вредных Е-добавок** (нитриты, азокрасители, подсластители под вопросом и т.д.) с пояснением, к каким последствиям для здоровья их связывают
- Отдельная проверка на **пальмовое масло**
- Настраиваемый **размер шрифта** для комфортного чтения
- **История проверок** и отдельная «безопасная полка» — то, что уже проверено и оказалось чистым
- Работает как **устанавливаемое приложение (PWA)** с офлайн-доступом к интерфейсу и истории
- Три параллельных источника данных о составе (см. ниже) плюс возможность **пополнять базу самому**

## Источники данных

| Источник | Что даёт | Покрытие |
|---|---|---|
| [Open Food Facts](https://world.openfoodfacts.org) | состав, добавки, Nutri-Score, NOVA | краудсорс, международный, неравномерное для локальных брендов |
| [Роскачество](https://rskrf.ru) | состав, рейтинг, Знак качества, нарушения | официальные лабораторные исследования, но узкий каталог (~13 000 товаров) |
| База сообщества (этот репозиторий) | состав, добавленный вручную через issue | растёт от вас 🙂 |
| Распознавание фото | состав прямо с упаковки | работает всегда, если есть фото, качество зависит от снимка |

Если ни один источник не знает товар — приложение честно покажет «Нет данных о составе», а не соврёт про мнимую безопасность.

## 🙏 Помогите пополнить базу

Самая частая причина, почему состав не находится — товар просто ещё никто не добавил ни в одну открытую базу. Особенно это касается локальных и региональных брендов: у крупных международных производителей всё обычно уже расписано, а какой-нибудь местный завод — нет.

**Если вы наткнулись на товар без состава в приложении** — потратьте одну минуту:

1. Нажмите **«Предложить состав»** прямо в приложении (кнопка появляется, если состав не найден) — штрихкод подставится автоматически
2. Или откройте вручную: [создать issue с составом товара](https://github.com/danya-bit0505/sostav-scan/issues/new?template=propose-composition.yml)
3. Перепишите состав **точно как на упаковке**, без сокращений и пересказа
4. После проверки состав появится в базе и будет доступен всем — в том числе вам, если решите проверить этот же товар ещё раз

Это по-настоящему помогает — база растёт исключительно за счёт того, что кто-то один раз потратил минуту на переписывание состава с этикетки. Если приложение оказалось вам полезно — лучший способ отблагодарить проект — добавить в него хотя бы один товар, которого там не хватало.

Все предложенные составы проходят проверку модератором вручную, прежде чем попасть в базу, — это защищает от ошибок и злоупотреблений.

## Как это устроено технически

Никакого сервера — статический сайт на GitHub Pages, один файл `index.html`. Все данные о составе запрашиваются напрямую из браузера в момент сканирования (Open Food Facts, Роскачество, база сообщества — через `raw.githubusercontent.com`), с несколькими резервными путями на случай блокировок/недоступности.

База сообщества устроена на **GitHub Issues + Actions**: пользователь заполняет форму → создаётся issue → после проверки модератором и лейбла `approved` GitHub Action сам коммитит файл в `data/community/{штрихкод}.json` → приложение подхватывает его при следующем поиске этого штрихкода.

```
├── index.html                                  — само приложение
├── manifest.json, sw.js, icon*                 — PWA (установка, офлайн)
├── data/community/{штрихкод}.json              — база сообщества
└── .github/
    ├── ISSUE_TEMPLATE/propose-composition.yml  — форма предложения состава
    └── workflows/approve-composition.yml       — автокоммит после одобрения
```

## Ограничения, о которых стоит знать

- Это **справочный инструмент, не медицинская рекомендация** — при серьёзных вопросах о питании консультируйтесь с врачом
- Роскачество тестирует ограниченный список товаров — отсутствие в их базе не означает, что товар плохой
- Open Food Facts заполняется волонтёрами — карточка товара может существовать без расшифрованного состава
- Распознавание фото зависит от качества снимка и освещения
